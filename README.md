# Movie Discovery and Watchlist API

A REST API for browsing a movie catalog and managing personal watchlists — built with ASP.NET Core and MongoDB, using a layered controller → service → repository architecture.

## Tech Stack

- C# / ASP.NET Core 8 (controller-based Web API)
- MongoDB (via Docker for local development)
- Swagger / OpenAPI for interactive API docs
- xUnit for testing

## Status

🚧 In active development. See Roadmap below for what's built vs. planned.
